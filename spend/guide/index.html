3จดรายจ่าย 💸

  1. กดปุ่ม ＋ วงกลมสีส้ม มุมขวาล่าง
  2. ด้านบนเลือก 💸 รายจ่าย (ค่าเริ่มต้น)
  3. พิมพ์ จำนวนเงิน ในช่องใหญ่
  4. แตะ หมวด เช่น อาหาร/เครื่องดื่ม เดินทาง/น้ำมัน
  5. รายละเอียด ไม่ใส่ก็ได้ เช่น ข้าวมันไก่
  6. วันที่ตั้งเป็นวันนี้ให้แล้ว เปลี่ยนได้ · เลือกจ่ายด้วย เงินสด / โอน / บัตร
  7. กด บันทึก เสร็จ!
⚡ จดหลายรายการติดกัน กด บันทึก + จดต่อ หน้าต่างจะไม่ปิด จดรายการถัดไปได้ทันที · ระบบจำหมวดล่าสุดให้

4จดรายรับ 💰

  1. กดปุ่ม ＋ เหมือนเดิม
  2. แตะ 💰 รายรับ ด้านบน (หมวดจะเปลี่ยนเป็นหมวดรายรับ)
  3. ใส่จำนวนเงิน แตะหมวด เช่น เงินเดือน ขายของ
  4. เลือกรับเป็น เงินสด / โอน / บัตร แล้วกด บันทึก
💡 ตัวเลขรายรับเป็นสีเขียว รายจ่ายเป็นสีแดง ดูง่ายไม่สับสน

5ดูสรุป (เมนู 📊 ภาพรวม)

ระบบสรุปให้อัตโนมัติทุกครั้งที่จด

  • รายรับ / รายจ่ายเดือนนี้ และเทียบกับช่วงเดียวกันของเดือนก่อน
  • คงเหลือ (รับ − จ่าย) และ งบรายจ่ายที่เหลือ (ถ้าตั้งงบไว้)
  • รายจ่ายหมดไปกับอะไร กราฟโดนัทแยกหมวด พร้อม %
  • รายรับ vs รายจ่าย 6 เดือน เห็นแนวโน้ม
  • รายจ่ายรายวัน และ จ่ายเยอะที่สุด 5 อันดับ
📅 ดูเดือนอื่น กดลูกศร ‹ › ข้างชื่อเดือน

6ดูรายการ ค้นหา ส่งออก Excel

เมนู 📋 รายการ ด้านล่าง

  • เลือกดู ทั้งหมด รายจ่าย รายรับ
  • พิมพ์ในช่อง 🔎 ค้นหา เช่น "ข้าว" "น้ำมัน"
  • ด้านบนบอกจำนวนรายการ และยอดรับ / จ่ายรวมของเดือน
  • กด ⬇️ ส่งออก Excel (CSV) เพื่อเปิดใน Excel หรือ Google Sheets

7แก้ไข / ลบรายการ

  1. ในหน้า 📋 รายการ แตะรายการที่ต้องการ
  2. หน้าต่าง แก้ไขรายการ จะเปิดขึ้น แก้จำนวน หมวด วันที่ได้
  3. กด บันทึก · หรือกด ลบ เพื่อลบรายการนั้น
↩️ จดผิดประเภท (เช่น รายรับจดเป็นรายจ่าย) แตะเปลี่ยน 💸/💰 ด้านบนได้เลย

8ตั้งค่า งบ และหมวด

เมนู ⚙️ ตั้งค่า

  • ชื่อที่แสดง เช่น "บ้านเรา" "ร้านป้าแดง"
  • งบรายจ่ายต่อเดือน เช่น 15,000 (ใส่ 0 = ไม่ตั้ง) ระบบจะบอกว่างบเหลือเท่าไหร่
  • หมวดรายจ่าย / หมวดรายรับ แก้ชื่อ เปลี่ยนอีโมจิ กด ＋ เพิ่มหมวด หรือ ลบ ได้
  • เสร็จแล้วกด บันทึกการตั้งค่า
⚠️ ปุ่ม ล้างรายการทั้งหมด จะลบทุกรายการ ใช้เมื่อต้องการเริ่มใหม่เท่านั้น · ถ้าเคยกด ✨ ข้อมูลตัวอย่าง แล้วจะเริ่มจดจริง ให้กดปุ่มนี้ก่อน

❓ คำถามที่พบบ่อย

ใช้หลายเครื่องได้ไหม (มือถือ + คอม / คนในบ้าน)

ได้ค่ะ เข้าด้วยอีเมล + รหัสผ่านเดียวกัน ข้อมูลจะซิงก์ให้ทุกเครื่อง ถ้าเข้าเครื่องใหม่ไม่ได้ ทัก LINE ร้านได้เลย

เปลี่ยนมือถือ ข้อมูลหายไหม

ไม่หายค่ะ ข้อมูลเก็บในระบบออนไลน์และร้านสำรองให้ทุกวัน เข้าระบบในเครื่องใหม่ข้อมูลจะกลับมาเอง

ลืมรหัสผ่านทำยังไง

หน้าเข้าสู่ระบบ กด "ลืมรหัสผ่าน?" ใส่อีเมลที่สมัคร ระบบจะส่งลิงก์ตั้งรหัสใหม่ให้ (เช็กในกล่องจดหมายขยะด้วย)

หมวดไม่ตรงกับที่ใช้จริง

ไปที่ ⚙️ ตั้งค่า แก้ชื่อหมวด เพิ่ม หรือลบได้ตามต้องการ แล้วกดบันทึกการตั้งค่า

อยากได้ข้อมูลไปทำต่อใน Excel

หน้า 📋 รายการ กด "ส่งออก Excel (CSV)" ไฟล์จะดาวน์โหลดลงเครื่อง เปิดด้วย Excel หรือ Google Sheets ได้เลย

ครบ 7 วันแล้วต้องทำยังไง

ถ้าถูกใจและอยากใช้ต่อ ทัก LINE ร้าน หรือกดปุ่มสั่งซื้อในระบบ ข้อมูลที่จดไว้ช่วงทดลองยังอยู่ครบ ไม่ต้องจดใหม่ ระบบไม่ตัดเงินอัตโนมัติ
