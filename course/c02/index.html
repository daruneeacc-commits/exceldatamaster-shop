สแกน QR พร้อมเพย์ แนบสลิป → ร้านตรวจแล้วส่งลิงก์คอร์ส/ไฟล์เข้าอีเมลให้ภายใน 2 ชม. (8:00–22:00) · สงสัยทัก LINE

เรียนจบแล้วทำอะไรได้

☑ ติ๊กแล้วเวลาขึ้นเองเวลาค้างไว้ ไม่เดินตามนาฬิกา กด F9 กี่ครั้งก็ไม่เปลี่ยน
🔴 มาสายขึ้นแดงเทียบเวลาเริ่มงานรายคน ตั้งผ่อนผันกี่นาทีก็ได้
🔒 กันพนักงานแก้เวลาล็อกชีต ติ๊กได้อย่างเดียว
📊 สรุปทั้งเดือน (ในไฟล์พร้อมใช้)วันมา · วันสาย · นาทีสายรวม รายคน

เนื้อหาในคอร์ส

  1. ทำหน้าตาตารางลงเวลา 22 คนหัวตาราง · ผสานเซลล์ · รูปแบบเวลา hh:mm:ss
  2. ใส่ช่องติ๊ก (Checkbox)Excel 365 แทรกได้เลย · รุ่นเก่าใช้ Developer + Cell link
  3. ติ๊กแล้วเวลาขึ้นเองและค้างไว้NOW · IF · N · เปิดคำนวณซ้ำ (หัวใจของคอร์ส)
  4. ผลลัพธ์ สาย / ตรงเวลา + ระบายสีแดงMOD · Conditional Formatting · ผ่อนผันเป็นนาที
  5. ล็อกชีต และใช้งานทุกวันป้องกันแผ่นงาน · คัดลอกแท็บวันใหม่

* เนื้อหาอาจปรับเล็กน้อยตอนเปิดคอร์สจริง

คำถามที่พบบ่อย

ดูคลิปได้ทางไหน

ดูผ่านมือถือหรือคอมได้ ใช้บัญชี Google ของอีเมลที่แจ้งตอนซื้อ (ไม่มี Gmail ก็สมัครบัญชี Google ฟรีด้วยอีเมลเดิมได้) ร้านจะเปิดสิทธิ์ให้อีเมลนั้น

ไม่เก่ง Excel เรียนได้ไหม

ได้ค่ะ คลิปสอนแบบช้า ทีละคลิก และมีไฟล์ที่ใช้สอนให้เปิดทำตามไปพร้อมกัน

ใช้ Excel เวอร์ชันไหน

Excel 2010 ขึ้นไป หรือ Microsoft 365 (Checkbox แบบแทรกได้เลยมีใน 365) · Google Sheets ใช้ได้ (เปิด "การคำนวณซ้ำ" ในการตั้งค่า)

อยากได้ไฟล์ไปใช้เลย ไม่อยากเรียน

เลือก "ไฟล์พร้อมใช้ 199.-" ได้เลยค่ะ ถ้าอยากให้ตอกบัตรด้วย PIN แล้วต่อเข้าเงินเดือนอัตโนมัติ ลองระบบลงเวลาออนไลน์ฟรี 7 วันที่ ระบบลงเวลา

เวลาไม่ขึ้น / มีเตือนการอ้างอิงแบบวงกลม

เปิด File › Options › Formulas › Enable iterative calculation (Maximum Iterations = 1) ในคอร์สสอนไว้แล้วค่ะ
