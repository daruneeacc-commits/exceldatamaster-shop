เรียนจบแล้วทำอะไรได้

⏰ คิด OT อัตโนมัติพิมพ์เวลาแบบ 18.30 ได้เงิน OT เป็นบาททันที
📅 แยกวันทำงาน / วันหยุดไฟล์รู้เองจากปฏิทินวันหยุด คิด 1.5 / 1 / 3 เท่าถูกเรท
⏱️ หักมาสายตั้งเวลาผ่อนผันได้ ช่องสายขึ้นสีแดงเอง
📊 สรุปรายคนทั้งเดือนรวม OT · ค่าทำงานวันหยุด · หักสาย พร้อมพิมพ์ให้หัวหน้าเซ็น

เนื้อหาในคอร์ส

  1. ตั้งค่าไฟล์ เวลาเข้า-เลิกงาน และวันหยุดเริ่มจากไฟล์เปล่า ทำตามได้ทุกขั้น
  2. สูตรแปลงเวลา 18.30 → เวลาจริง และคิด OT เป็นนาทีINT · MOD · TIME · MAX
  3. คิดเงิน OT ตามเรทวันทำงาน / วันหยุดค่าแรงต่อชั่วโมง · IF · COUNTIF วันหยุด
  4. หักมาสายและใส่สีอัตโนมัติConditional Formatting · Data Bar
  5. สรุปรายคนทั้งเดือน + เตรียมพิมพ์SUMIFS · COUNTIFS · ตั้งหน้ากระดาษ

* เนื้อหาอาจปรับเล็กน้อยตอนเปิดคอร์สจริง
